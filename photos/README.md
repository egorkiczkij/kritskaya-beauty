# Фото

Сюда кладутся фотографии для приложения.

- `avatar.jpg` — фото в круге наверху, квадратное.
- `cover.jpg` — картинка для превью ссылки в Instagram и мессенджерах, 1200×630.
- `work-01.jpg`, `work-02.jpg` и дальше — работы для портфолио. Имена должны совпадать с теми, что указаны в `config.js`.

Перед загрузкой уменьшите фото до 1200 px по длинной стороне и сохраните в JPG весом до 300 КБ. Иначе в Instagram и на мобильном интернете портфолио будет грузиться долго.
